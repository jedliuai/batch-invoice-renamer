# 按规则批量重命名发票

一个用于批量处理 PDF 发票的小工具。

它会读取发票 PDF 中的发票号码和金额，然后按照固定格式复制并重命名文件：

```text
发票号码+姓名+金额元.pdf
```

示例：

```text
26117000000957348288+刘永军+119.30元.pdf
```

## 功能特点

- 支持批量处理 PDF 发票。
- 支持选择整个文件夹进行处理。
- 支持多级子文件夹，会保留原来的目录结构。
- 自动识别发票号码和金额。
- 自动生成新的输出文件夹，不会直接修改原始发票文件。
- 如果重命名后文件名重复，会自动追加序号，避免覆盖文件。

## 环境要求

需要安装 Python，并安装 `pdfplumber` 依赖。

安装依赖：

```bash
pip install pdfplumber
```

如果你的电脑同时安装了多个 Python 版本，也可以尝试：

```bash
python -m pip install pdfplumber
```

## 使用方法

### 方法一：双击运行

1. 双击 `一键重命名.bat`。
2. 弹出窗口后，选择存放发票 PDF 的文件夹。
3. 程序会自动扫描该文件夹及其子文件夹。
4. 处理完成后，会自动打开输出文件夹。

输出文件夹会创建在原文件夹旁边，名称格式为：

```text
原文件夹名_已重命名
```

例如你选择：

```text
D:\发票
```

程序会输出到：

```text
D:\发票_已重命名
```

### 方法二：命令行运行

在项目目录中运行：

```bash
python rename_invoice.py
```

然后按弹窗提示选择发票文件夹即可。

## 修改姓名

如果需要修改重命名文件中的姓名，打开 `rename_invoice.py`，找到：

```python
USER_NAME = "刘永军"
```

把里面的名字改成需要的姓名即可。

## 重命名规则

当前输出文件名格式为：

```text
发票号码+姓名+金额元.pdf
```

例如：

```text
26117000000957348288+刘永军+119.30元.pdf
```

## 注意事项

- 程序只处理 `.pdf` 文件。
- 原始文件不会被改名或删除，程序会复制一份到新的输出文件夹。
- 如果某些 PDF 是图片扫描件，无法直接提取文字，可能会识别失败。
- 如果发票版式特殊，可能需要调整识别规则。
- 运行时如果出现缺少依赖的错误，请先安装 `pdfplumber`。

## 常见问题

### 1. 双击后窗口一闪而过怎么办？

先确认是否已经安装 Python 和 `pdfplumber`。

可以在命令行中运行：

```bash
python --version
python -m pip show pdfplumber
```

### 2. 为什么有些发票显示“无法识别”？

常见原因包括：

- PDF 是扫描图片，不包含可复制文字。
- 发票格式和当前识别规则不一致。
- 发票号码或金额在 PDF 中的文字提取结果不完整。

### 3. 会不会覆盖原来的发票？

不会。程序会把处理后的文件复制到新的输出文件夹，原始文件保持不变。
