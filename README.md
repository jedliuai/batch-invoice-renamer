# batch-invoice-renamer

中文 PDF 发票批量重命名工具。选择一个发票文件夹，它会自动读取 PDF 里的发票号码和金额，把文件复制到新目录，并按报销更容易整理的格式重命名。

```text
发票号码+姓名+金额元.pdf
```

例如：

```text
26117000000957348288+刘永军+119.30元.pdf
```

## 适合谁

- 经常需要整理电子发票、火车票、报销凭证的人。
- 需要把一批 PDF 发票改成统一命名格式的人。
- 希望保留原始文件，只在新文件夹里生成整理结果的人。
- 不想手动复制发票号码、金额再一个个改文件名的人。

## 它解决什么问题

报销前整理发票时，最麻烦的事情通常不是下载发票，而是把几十个 PDF 改成别人能看懂、自己也能追踪的名字。

这个工具做的事情很简单：

1. 选择一个包含 PDF 发票的文件夹。
2. 自动扫描该文件夹和所有子文件夹。
3. 从 PDF 第一页提取发票号码和金额。
4. 复制到新的“已重命名”文件夹。
5. 生成统一格式的新文件名。

原始文件不会被修改、移动或删除。

## 快速开始

### 1. 安装依赖

先确认电脑已经安装 Python，然后在命令行中运行：

```bash
python -m pip install -r requirements.txt
```

如果只想手动安装核心依赖，也可以运行：

```bash
python -m pip install pdfplumber
```

### 2. 双击运行

在 Windows 上直接双击：

```text
一键重命名.bat
```

然后在弹出的窗口里选择存放发票 PDF 的文件夹。

### 3. 查看结果

程序会在你选择的文件夹旁边创建一个新文件夹：

```text
原文件夹名_已重命名
```

例如选择：

```text
D:\发票
```

输出位置就是：

```text
D:\发票_已重命名
```

## 命令行使用

也可以在项目目录中运行：

```bash
python rename_invoice.py
```

运行后同样会弹出文件夹选择窗口。

## 支持的识别内容

当前主要识别：

- 发票号码
- 金额
- 常见电子发票
- 常见铁路/客票 PDF
- 中英文发票号码标识，例如 `发票号码`、`No.`、`Number`

## 能力边界

这个工具依赖 PDF 中可提取的文字内容。

以下情况可能识别失败：

- PDF 是纯图片扫描件，没有可复制文字。
- 发票版式非常特殊。
- 发票号码或金额在 PDF 文字提取结果中缺失。
- PDF 加密或损坏。

如果识别失败，程序会在窗口里显示“无法识别”，不会破坏原始文件。

## 修改姓名

如果需要修改文件名里的姓名，打开 `rename_invoice.py`，找到：

```python
USER_NAME = "刘永军"
```

把姓名改成你需要的内容即可。

## 常见问题

### 双击后窗口一闪而过怎么办？

通常是 Python 或依赖没有安装好。可以在命令行中检查：

```bash
python --version
python -m pip show pdfplumber
```

### 会覆盖原来的发票吗？

不会。程序只会复制文件到新的输出文件夹。

如果多个 PDF 识别出相同的新文件名，程序会自动追加 `_2`、`_3` 这样的序号，避免覆盖。

### 为什么不直接修改原文件？

发票文件通常用于报销、归档或审计，原始文件最好不要被自动脚本改动。复制到新目录更稳妥，也方便人工复核。
